# MORI

MORI 是一个为个人使用设计的桌面陪伴与心理资源导航工具。它帮助你整理当下的感受、把难以开口的话写成草稿、保存自己认可的现实支持，并通过一只会呼吸、散步、看书和睡觉的小桌宠，为日常留出一个安静角落。

MORI 不是心理咨询师、治疗师、医生、诊断工具或紧急服务，也没有真人实时值守。它不会替你联系任何人。

## 本地启动

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

不配置模型时，页面会使用本地演示回复。右上角“连接模型”支持：

- OpenAI 原生接口
- Anthropic Claude 原生接口
- Google Gemini 原生接口
- OpenAI 兼容接口，包括 OpenRouter、硅基流动及其他兼容服务

保存模型设置时，MORI 会先发送一次真实 API 验证请求；验证成功后才显示“模型可用”。模型配置和 API Key 只保存在当前浏览器标签页，不写入项目文件。使用外部模型时，对话内容会发送给你选择的服务商，请按自己的隐私要求选择模型和服务。

线上 Pages 版本只能连接可从互联网访问的 HTTPS 模型接口，不能连接你电脑上的 `localhost`（例如本机 Ollama、LM Studio）。如需本机模型，请在本机运行 MORI。

## 个人功能

- MORI 的发呆、散步、看书、睡觉、伸懒腰、表情和自由拖动
- 个人对话与通用大模型接口
- 表达整理卡与本地草稿信箱
- 自定义支持背包
- 只保存在本机浏览器的心理花园与每周回顾
- 在高紧迫表达出现时，优先显示现实安全步骤和公开官方资源

## 安全边界

紧急提示中的 120、110 和 12356 明确适用于中国大陆；人在其他国家或地区时，应使用当地已经核验的急救与危机支持渠道。MORI 不会编造机构、联系方式、开放时间、保密承诺或已经完成的外呼行动。
